A secure PHP web application with user authentication, registration, two-factor authentication (Google Authenticator), session management, and an admin panel.

Secure login/logout system with password hashing.
Create new accounts with validation.
Two-Factor Authentication (2FA) - Google Authenticator TOTP integration.
Persistent user sessions with timeout protection.
Admin Panel: Manage users, view statistics, and system administration.
View user information and statistics.
Distinguish between regular users and administrators.
Bootstrap-based responsive design.
Dynamic user listing and searching.
